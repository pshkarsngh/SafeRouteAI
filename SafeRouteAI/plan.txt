3. INCIDENT SEARCH FLOW
-----------------------
User enters route
        │
        ▼
Fetch route path from Google Maps API
        │
        ▼
LLM extracts key locations/road names
        │
        ▼
Incident Searcher queries:
  ├─ NewsAPI / Google News for recent accidents
  ├─ Traffic incident APIs (if available)
  └─ Stored MongoDB cache (check TTL)
        │
        ▼
Parse & classify incidents (type, severity, date)
        │
        ▼
Dynamic score adjustment:
  base_score = hazard_density_score
  incident_penalty = sum(incident_severity * recency_weight)
  final_score = base_score - incident_penalty
        │
        ▼
Return score + incident summary to frontend


4. SAFETY SCORING FORMULA
-------------------------
Base Score = 100
Hazard Penalty    = Σ (hazard_severity * hazard_weight)
Incident Penalty  = Σ (incident_severity * recency_factor)
Preference Bonus  = match_llm_preferences(route, user_query)

Final Score = Base - Hazard_Penalty - Incident_Penalty + Preference_Bonus
             (clamped to 0-100)

Severity Weights:
  critical  = 25 pts
  warning   = 12 pts
  info      = 5 pts

Recency Factor (incidents):
  < 1 day   = 1.0
  < 1 week  = 0.7
  < 1 month = 0.4
  > 1 month = 0.1


5. DATABASE SCHEMA
------------------
routes:        { _id, start, end, polyline, safety_score, created_at }
hazards:       { _id, route_id, type, severity, location, image_url }
incidents:     { _id, route_id, title, source, severity, date, description, url }
user_queries:  { _id, start, end, preferences, llm_response, created_at }
